# Bayan Beans | بن بيان

متجر إلكتروني لبيع القهوة المحمصة والمطحونة، مبني بـ HTML و CSS و JavaScript في **ملف واحد** (`index.html`) يحتوي على كل شيء بما فيه الصور واللوجو، فلا يحتاج أي ملفات أخرى.

## المميزات

- شاشة افتتاحية بلوجو بن بيان قبل دخول الموقع
- تصفح المنتجات والتصنيفات والبحث والفلترة
- اختيار الوزن ودرجة التحميص ونوع الطحن
- سلة مشتريات وكود خصم وإتمام الطلب وتتبع الطلب
- المفضلة وحساب العميل
- الأسعار بالريال السعودي (ر.س)
- تصميم متجاوب مع الموبايل والكمبيوتر

## الرفع على GitHub Pages

1. أنشئ مستودعًا (Repository) جديدًا على GitHub.
2. ارفع الملفين `index.html` و `README.md` في الجذر (Add file ← Upload files).
3. من **Settings ← Pages** اختر Source = `Deploy from a branch`، و Branch = `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط:
   `https://USERNAME.github.io/REPO-NAME/`

## التعديل

افتح `index.html` بأي محرر نصوص:

- **المنتجات والأسعار:** ابحث عن `const P0=[` — السعر هو الرقم السابع في كل سطر (سعر 500 جرام بالريال).
- **أسعار الأوزان:** المصفوفة `const W=`.
- **الشحن:** الدالة `tot()` — الشحن 4 ر.س ومجاني فوق 45 ر.س.
- **كود الخصم:** `BAYAN10` (خصم 10%) في دالة `coupon()`.
- **رقم الهاتف وواتساب والبريد:** أرقام تجريبية، ابحث عن `wa.me` و `0100 000 0000`.
